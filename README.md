# 🧠 Kaun Banega Crorepati (KBC) - React + FastAPI Project

This is a full-stack web-based quiz game inspired by "Kaun Banega Crorepati (KBC)" using **React** for frontend and **FastAPI** for backend. The game includes lifelines, rules pages, score tracking, and smooth user flow.

---

## 🚀 Features

- 🎮 Quiz gameplay with question levels
- 🧩 Lifelines (like 50:50, audience poll, etc.)
- 📖 Rules and instructions before game start
- 🎵 Background music and delays for real feel
- 🔗 Connected frontend-backend (React ↔ FastAPI)

---

## 🛠️ Tech Stack

| Frontend  | Backend  |
|-----------|----------|
| React.js  | FastAPI  |
| HTML/CSS  | Python   |
| JavaScript | Uvicorn (server) |
